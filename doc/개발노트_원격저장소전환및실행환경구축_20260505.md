### 이슈 / 특이사항

- **PowerShell stderr 노이즈**: bun/git가 진행 메시지를 stderr로 출력해서 PowerShell이 `NativeCommandError`로 표시함. 실제 종료 코드는 0이며 동작에 영향 없음. (CLAUDE.md PowerShell 가이드에서도 명시된 동작)
- **초기 `bun install` 실패**: `tree-sitter-powershell` 빌드 시 `common.gypi not found` 에러 발생. Node 헤더 캐시 누락이 원인이었으며 `node-gyp install`로 해결.
- **bun.lock 변경**: 기존 anomalyco의 lockfile이 husky 등의 정확한 버전을 잡지 못했던 상태로 보임. install 후 자동 정합 → 커밋 포함.
